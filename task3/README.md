# Задача 3: Распределение дополнительных задач

## Условие

Вася выполняет N домашних заданий, в каждом по M задач. За решение x задач в задании он получает S[x] баллов (S — неубывающая последовательность). Уже решено P[i] задач в i-м задании. До конца семестра можно решить ещё не более K задач (любые, из любых заданий). Нужно распределить эти K задач так, чтобы максимизировать суммарные баллы.

## Входные данные

- Первая строка: N, M, K (1 ≤ N, M ≤ 500, 1 ≤ K ≤ N·M)
- Вторая строка: N целых чисел P[i] (0 ≤ P[i] ≤ M) — уже решённые задачи
- Третья строка: M+1 целых чисел S[0..M] — баллы за 0..M задач (S[i] ≤ S[i+1])

## Выходные данные

Одно число — максимальный суммарный балл.

## Пример

**Ввод:**
4 4 3
4 2 3 1
0 1 3 6 10

**Вывод:**
31

## Подход к решению

1. Считаем базовые баллы: sum(S[P[i]]).
2. Для каждого задания вычисляем приросты баллов за добавление 1,2,…, (M-P[i]) задач.
3. Задача сводится к рюкзаку: выбрать суммарно K приростов (с ограничением, что для каждого задания приросты берутся подряд).
4. Решаем динамическим программированием: dp[t] = максимальный дополнительный балл при t добавленных задачах.
5. Ответ = base + max(dp).
