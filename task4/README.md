# Задача 4: QR-код — лексикографически минимальная матрица

## Условие

Дана матрица N × M из 0 и 1. Разрешено любое количество циклических сдвигов строк (вертикально) и столбцов (горизонтально). Нужно получить из неё лексикографически минимальную матрицу (все строки выписаны в одну строку). Сдвиги можно применять в любом порядке.

## Входные данные

- Первая строка: N и M (1 ≤ N, M ≤ 1000)
- Следующие N строк: по M символов (0 или 1)

## Выходные данные

N строк — лексикографически минимальная матрица, достижимая с помощью циклических сдвигов.

## Пример

**Ввод:**
3 3
100
011
101

**Вывод:**
001
110
011

## Подход к решению

1. Сортируем исходные строки.
2. Перебираем возможные сдвиги строк (какая строка станет первой).
3. Для каждого сдвига перебираем сдвиги столбцов.
4. Ищем минимальную комбинацию (сравниваем полные строки матрицы).
5. Оптимизация: предварительно находим минимальную возможную первую строку и перебираем только те сдвиги, которые её дают.
