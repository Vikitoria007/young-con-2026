# Задача 1: Сортировка по частоте

## Условие (своими словами)

Дан массив целых чисел. Нужно переставить его элементы так, чтобы:

- Числа, которые встречаются чаще, стояли раньше.
- Если два числа встречаются одинаковое количество раз, то раньше ставится то, которое первым появилось в исходном массиве.

## Входные данные

- Первая строка: число `N` (1 ≤ N ≤ 1000)
- Вторая строка: `N` целых чисел

## Выходные данные

Переупорядоченная последовательность (числа через пробел).

## Пример

**Ввод:**
5
2 1 2 1 2

**Вывод:**
2 2 2 1 1

## Решение

Алгоритм:
1. Подсчитать частоту каждого числа.
2. Запомнить индекс первого появления каждого числа.
3. Отсортировать уникальные числа по двум ключам:
   - по убыванию частоты
   - при равной частоте — по возрастанию индекса первого вхождения
4. Для каждого числа из отсортированного списка вывести его столько раз, какова его частота.
