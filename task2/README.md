# Задача 2: Разделение логов на две арифметические прогрессии

## Условие

Дан массив моментов времени (n чисел). Нужно разделить их на две группы так, чтобы в каждой группе числа образовывали арифметическую прогрессию (разность может быть любой, в том числе 0). Порядок элементов в группах не важен — на выводе их нужно отсортировать по возрастанию.

Если это невозможно, вывести `-1`. Если возможно — вывести сначала размер первой группы и её элементы, затем размер второй группы и её элементы.

## Входные данные

- Первая строка: `n` (2 ≤ n ≤ 100000)
- Вторая строка: `n` целых чисел (1 ≤ t_i ≤ 10^9)

## Выходные данные

- `k` (размер первой группы)
- `k` чисел (первая группа, по возрастанию)
- `m` (размер второй группы)
- `m` чисел (вторая группа, по неубыванию)

Если решения нет — `-1`.

## Пример

**Ввод:**
4
2 1 2 4  

**Вывод**
2
1 2
2
2 4 


## Подход к решению

1. Сортируем массив.
2. Пробуем разные варианты:
   - первая прогрессия начинается с первого элемента, шаг — разность первого и второго (или шаг 0)
   - первая прогрессия начинается со второго элемента
3. Жадно собираем первую прогрессию (берём все доступные элементы).
4. Остаток проверяем на арифметическую прогрессию.
5. Если подошло — выводим результат.
6. Если ни один вариант не подошёл — выводим `-1`.
